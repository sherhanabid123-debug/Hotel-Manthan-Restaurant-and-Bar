# Hotel Manthan Restaurant and Bar

**Live site:** [https://hotel-manthan-restaurant-and-bar.vercel.app](https://hotel-manthan-restaurant-and-bar.vercel.app)

Website for Hotel Manthan, a restaurant and bar in Mumbai, built with plain HTML, CSS, and JavaScript.

## Features

- Hero, about, and gallery sections
- Signature dish and cocktail showcase
- Downloadable menu (PDF)
- Fully responsive layout

## Tech stack

- HTML5
- CSS3 (custom, no framework)
- Vanilla JavaScript

## Project structure

```
index.html    Main page
styles.css     Styling
script.js      Interactions
images/        Site and gallery images
Menu.pdf       Downloadable menu
```

## Running locally

This is a static site with no build step. Just open `index.html` in a browser, or serve it locally:

```bash
npx serve .
```
